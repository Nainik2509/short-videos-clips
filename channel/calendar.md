# Content calendar

## Weekly rhythm (start with 5 a week; add more only when you can keep quality)

| Day | Series | Note |
|---|---|---|
| Mon | Facts | 15–25 s |
| Tue | Kahani | Part N of the running sub-series |
| Wed | Cartoon | Pinku aur Dadi episode |
| Thu | Facts | |
| Fri | Kahani | |
| Sat | (rest, or bonus Cartoon) | Review analytics, write next week's scripts |
| Sun | (rest) | Prepare 3 scripts ahead |

Post at the **same time every day** (pick one slot and keep it for 30 days before testing another).
Always keep **5+ finished Shorts** scheduled ahead so a busy week never breaks the rhythm.

## First 30 days

| Week | Goal | Do |
|---|---|---|
| 1 | Channel ready + 5 Shorts | Finish the setup checklist; make Facts #1–2, Kahani Part 1–2, Cartoon #1; schedule |
| 2 | Find what hooks | Keep the rhythm; compare "viewed vs swiped away" per series |
| 3 | Double down | Make 2 more of whichever series keeps viewers; rewrite hooks of the weakest |
| 4 | Decide | Keep 3 series, or focus on the best 2. Update the backlog with 10 new approved topics |

## Batch routine (saves the most time)

- **One session:** write and approve 3–5 scripts (all `script.md` + `voice.txt`).
- **Second session:** record or generate all voices, run timings for each.
- **Third session:** fill scenes, review storyboards, render, run `npm run youtube -- <slug>`, schedule.
